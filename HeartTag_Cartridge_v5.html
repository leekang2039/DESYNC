Heart Tag 카트리지

팔찌 없이 어깨의 Heart Tag 하나로 갑니다. 대상 앞에서 상호작용하면 장착한 카트리지로 Heart Tag가 일을 하고, 그동안 어깨 너머로 패턴이 떠서 "지금 하고 있다"를 보여줘요. 전체 지도 대신 Heart Tag에게 말을 걸면 길을 바닥에 표시해 줘요.

W/스페이스 이동 · E 상호작용 · T 청음(“Hey T / Hey H / Para”) · V 총 변형(권총 ↔ 소총) · 클릭 사격 · R 재장전 · 1/2/3 카트리지 교체 · 복도 끝에서 X.

조작
카트리지 슬롯 (누르면 교체)
상호작용 (E) — 하는 동안만 패턴
PULSE물체: 눈금 휠이 돌다 멈추며 식별 → 윤곽선 · 식별하면 Heart Tag가 정보를 기억 DECODER문: 텀블러 트랙 4줄 → 열림 · 단말: 암호 트랙 3줄 → 화면 점등 ANCHORDESYNC 문(X): 좌표 고리 두 개가 맞물리고 접혀 다른 공간으로 이미 해독고리 하나만 0.5초
청음 (T) — Heart Tag에게 말하기
길 찾아줘바닥에 화살표 + 목적지 빛기둥 (전체 지도 없음) ○○ 어디 있어?분석한 대상이면 정확히 표시, 아니면 대략적 방향만 → 탐험 동기 ○○ 정보분석한 것만 설명서처럼 알려줌 이스터에그누구야 · Para · 노래 · 농담 · 몇 시 … 마이크브라우저가 허용하면 음성 인식, 아니면 글자 입력 (미리보기 화면에선 글자)
총 (V) — 원할 때 직접 변형
권총 → 소총덮개가 밀려 나오며 총열 연장 → 레일 내려옴 → 개머리판이 프레임 아래서 뒤로 펼쳐짐 → 조준경이 일어섬 → 탄창 연장 (0.45초, 변형 중 사격 불가) 잔탄슬라이드 뒤 작은 표시창: 숫자 · PST/RFL · /15·/30 · 막대 (모드별 탄창 따로)
투사
위치왼쪽 어깨(화면 밖 아래)에서 레이저 4줄 → 원형 패턴이 펼쳐짐 (지도와 같은 문법) 모양Heart Tag가 둥근 장치라 패턴도 고리형 · 창은 위쪽 · 가운데는 느리게 도는 코어 베젤
