팔찌 아크 HUD

조준하면 팔찌가 레이저를 쏘고, 지도처럼 작은 격자 패널이 전개돼요. 드론·기어·마킹 정보는 바뀔 때만 잠깐 나타나요. 문 열기·해킹·스캔 키를 누르면 손목이 올라오고 팔찌 이음새가 하늘색으로 바뀌면서, 손목 바깥쪽 짧은 호에서 트랙들이 흐르다 창에 맞춰 고정되고 빔/스캔 이펙트가 나옵니다.

화면 우클릭 유지 = 조준, 조준 중 좌클릭 = 사격, 마우스 이동 = 시선.

전투
팔찌 동작
조준 HUD
전개지도와 같은 순서: 팔찌 이미터에서 레이저 4줄 → 코너 브래킷 → 격자 유리 패널이 가운데서 열림 → 내용. 레이저는 옅게 유지 패널 내부 4종HUD 버튼으로 전환 · ANALYSIS(진행 링 + 자간 탄종) · TYPE(큰 숫자 하나) · SIGNAL(남은 탄 = 파형 길이, 사격 시 스파이크) · TERMINAL(장비 로그 행 + 최근 이벤트 타이핑) 데이터 행드론·기어·마킹은 필요할 때만 패널 아래 한 줄씩
팔찌 동작 UI
처음 대상글자 없이 해독 패턴만 크게: 텀블러 트랙(문) · 암호 트랙 + 반송파 노이즈(해킹) · 눈금 휠(스캔). 풀리는 순간 패턴 전체가 한 번 번쩍. 조준하면 작은 진행 호로 접힘 반복 대상HUD 없음. 팔찌 이음새 빛 회전 + 빛 고리 + 짧은 빔 (약 0.6초)
